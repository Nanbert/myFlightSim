# 737 第一档面板 — 2D 真实渲染设计图（仅设计，不改游戏代码）

只画第一档的两个面板——它们对应的功能在模拟里已有真实状态与飞行后果，将来实现时点击立即生效。

## 面板 1 · 起落架/襟翼面板（真实位置：主仪表板）
覆盖键位：U 起落架、F/V 襟翼
- 起落架手柄（DOWN/OFF/UP 三档、带拉出把手）+ 3 个指示灯：红 TRANSIT/UNLOCK ×2、绿 DN；灯逻辑按真实状态画（放伞中红灯亮、锁定后熄灭/绿亮），hover 显示"原 U 键 → 鼠标点击"
- 襟翼表盘：UP/1/2/5/10/15/25/30/40 刻度 + 指针（映射现有 flap_pos_deg 连续值）；档位可点击演示，指针缓动到档位

## 面板 2 · 操纵台条带（真实位置：中央操纵台）
覆盖键位：L 减速板、K 反推、B 刹车、Z/X/T 配平、Shift/Ctrl 油门
- 减速板手柄 ARMED / FLIGHT DN / UP 三档 + 绿色 EXTENDED 指示灯（现 speedbrake_pos 有 0.6s 行程，演示随之缓动）
- 反推 REV 琥珀灯（仅着地亮，对应 reverse_pos 行程）
- 停留刹车开关（图上标注"新增"——现在只有自动驻车，实现时补状态）
- 配平轮 + 配平指示器（原 Z/X 斜坡、T 重新配平）
- 油门把手 + N1 读数条（原 Shift/Ctrl）

## 可点击演示
每个开关/手柄可交互：点击切换档位 → 指示灯/指针/手柄按模拟里的行程时间缓动；hover 显示"原键位 → 未来鼠标操作"提示。
